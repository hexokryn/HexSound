# HexSound 0.13.0

## Русский

Приложение перенесено с Electron на C++20 и Qt Quick. Полностью обновлены навигация, нижний плеер и настройки. Каталог и воспроизведение работают через официальный SoundCloud.

- 32 темы, поиск настроек и скрываемая боковая панель.
- Два отключаемых фона с реакцией на курсор и нажатия.
- Собственный плеер с громкостью, обложкой и текстом песни из LRCLIB или LRC.
- «Моя волна» по лайкам SoundCloud без API-ключа.
- Импорт CSV/TSV/JSON в новый плейлист после проверки совпадений и отдельного подключения SoundCloud API.
- Discord Rich Presence через локальный IPC. Для включения нужен публичный Application ID из Discord Developer Portal; по умолчанию функция выключена.
- Кнопка обновления в верхней панели. Следующие обновления C++-версии используют проверяемый ZIP и отдельный помощник с резервной копией и откатом, без запуска установщика.

**Установка:** скачайте `HexSound-0.13.0-setup.exe`. Setup устанавливает приложение для текущего пользователя. Для переносного запуска распакуйте `HexSound-0.13.0-native-portable.zip` целиком и запустите `HexSound.exe`. SHA-256 файлов указан в `HexSound-0.13.0-SHA256SUMS.txt`.

Новая версия использует отдельный профиль: потребуется снова войти в SoundCloud. Данные старой версии сохраняются. Setup нужен для первой установки и перехода с Electron.

Выпуск для Windows x64. Сборка использует Qt 6.12.1 и отдельный Qt WebEngine 6.140.0. Автоматические проверки используют локальную аудиозапись и тестовый API; реальный вход в частный аккаунт, API-запись и Discord с пользовательским Application ID ими не проверяются. Linux проверяется отдельной CI-задачей и в этот релиз не входит. Установщик не имеет цифровой подписи.

## English

HexSound now uses C++20 and Qt Quick instead of Electron. Navigation, playback controls and settings have been rebuilt. SoundCloud's official website supplies the catalog and audio playback.

- 32 palettes, searchable settings and collapsible navigation.
- Two optional backgrounds that respond to pointer movement and clicks.
- Persistent player with volume, artwork and lyrics from LRCLIB or LRC files.
- Personal radio based on SoundCloud likes, without an API key.
- Reviewed CSV/TSV/JSON import into a new playlist with separate SoundCloud API authorization.
- Native Discord Rich Presence over local IPC; requires your own public Application ID and is disabled by default.
- Updates from the top bar use a verified ZIP, a separate helper, backup and rollback. Subsequent native updates do not launch Setup.

Use `HexSound-0.13.0-setup.exe` for a per-user installation. For portable use, extract the entire `HexSound-0.13.0-native-portable.zip` and run `HexSound.exe`. Checksums are in `HexSound-0.13.0-SHA256SUMS.txt`.

Sign into SoundCloud again: the native app uses a separate profile and preserves the Electron app's data. Setup is needed for the initial installation and migration from Electron.

Windows x64 release built with Qt 6.12.1 and Qt WebEngine 6.140.0. Automated checks use local audio and API fixtures; they do not verify private-account login, real API writes or live Discord presence with a user's Application ID. Linux has a separate CI job and is not included in this release. The installer is not code-signed.
