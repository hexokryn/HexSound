# Перенос из файла в SoundCloud

Настройки → Импорт из файла. Поддерживаются CSV, TSV и JSON со списком треков. Это перенос метаданных, а не загрузка аудио. Другие музыкальные сервисы не подключаются.

CSV/TSV: title или name, artist, duration в секундах или mm:ss. Вместо duration можно duration_ms, одновременно оба поля не допускаются. Поддерживаются BOM, русские заголовки, разделители запятая/точка с запятой/табуляция и кавычки. JSON: массив записей или объект с tracks; старый экспорт с providers/tracks остаётся допустимым форматом файла.

Ограничения парсера: 10 МБ, до 50 000 записей, ограниченные размеры ячеек/колонок. Поиск API за один перенос — от 1 до 5000 записей. При большем файле разделите список. Название обязательно; неверная длительность останавливает импорт.

Найдите совпадения и проверьте каждую строку. Автовыбор требует достаточной уверенности и отрыва от второго результата. При нехватке длительности автоподтверждения нет. Remixes, live, instrumental и другие издания сравниваются отдельно. В неоднозначной строке укажите кандидата или явный пропуск. Затем задайте имя нового приватного плейлиста и подтвердите создание.

Для записи нужен отдельный SoundCloud API-доступ. transfer-journal.json сохраняется до сетевой записи. Неизвестный результат создания плейлиста нельзя автоматически повторять: сначала проверьте SoundCloud. Продолжение работает только для известного плейлиста того же API-аккаунта, читает полный состав и добавляет записи без удаления существующих. Неполный ответ останавливает запись.

Файлы: native/MusicData.cpp, native/Services.cpp, native/Controller.cpp. Реальные сетевые изменения аккаунта здесь не проверялись.
