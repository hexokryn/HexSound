# HexSound 0.9.1

Единый интерфейс, синхронизация веб-библиотеки SoundCloud, 18 вариантов фона и обновления через GitHub из версии 0.9.0. Дополнительно убран лишний футер из подразделов настроек, исправлено отображение текущей версии и прокрутка к выбранной вкладке на узких окнах.

Unified interface, SoundCloud web-library import, 18 background choices and verified GitHub updates from 0.9.0. This patch also fixes settings subpage footer, version display and active-tab visibility on narrow windows.

Перед установкой завершите прежнюю версию через трей → Выйти. Для перехода с 0.8.1 установите этот выпуск вручную; последующие обновления предлагаются при запуске. Windows EXE без Authenticode-подписи.
