# Воспроизведение и волна

Музыка воспроизводится официальным веб-плеером SoundCloud. Обзор, лента, лайки, плейлисты и история — страницы SoundCloud с темой HexSound. Нижняя панель и экран текста управляют этим же плеером. Переходы внутри сайта сохраняют воспроизведение, если SoundCloud обрабатывает их своим роутером.

«Моя волна» использует лайки и доступные плейлисты текущей веб-сессии. При первом запуске подборки приложение читает видимые записи из SoundCloud. Поиск похожих треков работает через веб-каталог без API-ключей. При недоступности поиска доступен явно обозначенный микс известных треков. Для запуска записи открывается её страница SoundCloud; подтверждение воспроизведения читается из плеера сайта.

Нижняя панель показывает фактический текущий трек. Обложка открывает экран текста. Если точные часы недоступны, приложение не придумывает таймкоды. Текст можно найти через LRCLIB или открыть из своего LRC-файла.

Импорт файлов находится в настройках. Обычный веб-вход не даёт прав API на создание плейлистов: для переноса нужен отдельный SoundCloud API-доступ.
