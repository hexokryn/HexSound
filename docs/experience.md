# Волна, очередь и своя коллекция

## Моя волна

Добавьте любимую музыку в медиатеку и подключите API хотя бы одного каталога. Откройте **Моя волна → Новая подборка**. Обычного входа на сайте для поиска через API недостаточно.

HexSound выбирает несколько треков из библиотеки, запрашивает похожие записи в SoundCloud и экспериментальном адаптере Яндекс Музыки, дополняет их поиском по исполнителям. Spotify и YouTube используют поиск по исполнителям. Под каждым результатом указана причина выбора. Это собственный подбор HexSound; алгоритм Яндекс Музыки не используется.

В режиме «Больше нового» исключаются записи, уже находящиеся в библиотеке. «Знакомые исполнители» позволяет больше треков одного артиста. Оценка ♡ повышает вес музыки при следующем подборе, − исключает запись, ручной переход к следующему треку откладывает пропущенную запись на неделю. Кнопка + добавляет результат в медиатеку.

Подбор ограничен 18 запросами, а YouTube — двумя поисками по исполнителям за подбор. Волну можно остановить. Последняя удачная подборка сохраняется между запусками; без подключения интернета новые результаты не подставляются. Доступность найденной записи не гарантирует доступность её аудиопотока.

## Очередь и плеер

В меню ••• трека выберите «Слушать далее» или «В очередь». Выбранные записи из медиатеки можно добавить сразу. Порядок меняется перетаскиванием и стрелками. Очередь, перемешивание и повтор сохраняются на устройстве.

Локальные файлы и доступные через API потоки SoundCloud воспроизводятся своим аудиодвижком, включая автоматический переход в очереди и повтор. SoundCloud может предоставлять только превью или отказывать в потоке; приложение сообщает об этом. Для остальных источников открывается официальный веб-плеер. Автоматический запуск и переход в нём зависят от доступных команд сайта; ручная кнопка «Следующий» переключает очередь HexSound.

Кнопка «Мини-плеер» находится над большим плеером. Его можно закрепить поверх окон, закрыть отдельно или вернуться в главное окно. Текущая строка текста появляется при наличии синхронизированного LRC и известных часов воспроизведения.

## Файлы, теги и умные плейлисты

В меню **Медиатека → Музыка на устройстве** выберите папку. Поддерживаются MP3, FLAC, WAV, OGG, OPUS, M4A, AAC и AIFF; фактическое воспроизведение зависит от контейнера и доступных кодеков. Для обновления выберите ту же папку. Изменённые файлы перечитываются, неизменённые берутся из индекса. Символические ссылки не обходятся.

Удаление папки из коллекции убирает индекс, сохраняя аудиофайлы. Физические пути остаются в локальном индексе и не попадают в экспорт медиатеки. Экспорт JSON сохраняет метаданные и ссылки; резервная копия аудиофайлов делается отдельно.

Через ••• можно назначить треку теги. Умный плейлист сочетает теги, сервис, длительность и дату добавления; порядок доступен по названию, новизне или времени прослушивания. Сохраняются правила, поэтому состав меняется при изменении медиатеки. На экране показывается до 500 совпадений.

В «Совпадениях» можно объединить предложенные записи или разделить их источники. Для произвольного объединения выберите от двух до двенадцати записей в медиатеке. Разные версии песен проверяйте вручную. Решения сохраняются в экспорте библиотеки; удалений из сервисов не происходит.

## История и незавершённые переносы

История учитывает продвижение известных часов при воспроизведении. Паузы, перемотки и неизвестные часы не добавляют время. Прослушивание засчитывается после 30 секунд либо половины короткого трека. Статистика и оценки хранятся локально; историю можно очистить.

В «Истории переносов» доступны результат, отчёт JSON и продолжение незавершённой операции. Продолжение требует того же аккаунта и полного чтения целевого плейлиста: уже находящиеся там записи повторно не добавляются. Если сервис не подтвердил создание плейлиста, повторное создание автоматически не выполняется — сначала проверьте сервис вручную.

Для проверки без аккаунтов: `npm test`, `npm run check:library`, `npm run check:experience`. Последняя команда создаёт изолированный профиль, генерирует WAV, проверяет реальное аудио, перемотку, автоматический переход, мини-плеер и 35 сочетаний экранов и размеров. Демонстрационная волна использует подставной каталог и не обращается к личным аккаунтам.
