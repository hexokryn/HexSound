# Плеер, текст и волна

Одна официальная страница SoundCloud воспроизводит музыку. Controller::control направляет команды через DOM-мост, receive получает snapshot и обновляет оболочку. Нижняя панель остаётся доступна на всех экранах. Перемотка и громкость управляют этой же страницей. Её скрытие при переходе в настройки или к тексту не создаёт второго аудиоплеера.

Текст: LRCLIB или локальный LRC, повторные таймкоды и offset. При точном времени используется audio/mediaSession, иначе наблюдение шкалы сайта. Сетевой ответ от предыдущего трека отбрасывается. Текущая строка меняет прозрачность и положение, прокрутка возвращает её в центр. Полностью отключить движение можно в оформлении. Наклон обложки включается отдельно в настройках звука и плеера.

Волна строится без API по лайкам текущего веб-аккаунта, а находки ищутся по исполнителям и настроению в SoundCloud. Баланс, знакомое, открытия; любое настроение, спокойное, энергичное, для фокуса. Это эвристическая подборка, не модель Яндекс Музыки. Оценки сохраняются локально. Дизлайки исключают трек. Конец воспроизведения определяется наблюдаемым событием ended, без фиктивных таймеров окончания.

Сборщик временно открывает страницу в том же изолированном профиле, ограничивает время и количество результатов, затем уничтожает WebEngineView. Старые результаты не применяются после отмены или смены аккаунта.

Для проверки без аккаунта: --smoke artifacts/native-smoke. Проверочный WAV действительно воспроизводится, затем проверяются pause/volume и SPA-переход. Частный каталог и реальный SoundCloud-поток требуют отдельной проверки.
