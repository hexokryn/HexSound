# HexSound 0.9.2

- «Моя волна» работает без API-ключей: поиск и похожие записи читаются из обычной сессии SoundCloud. При недоступном каталоге доступен явно обозначенный микс из медиатеки.
- Волна начинает играть музыку из библиотеки сразу, пока новые результаты подбираются в фоне.
- Клик по названию или обложке запускает трек, сохраняя открытый экран медиатеки.
- Постоянный нижний плеер: обложка, название, пауза, предыдущий/следующий, перемотка, громкость, очередь и переход к тексту.
- Веб-плеер передаёт фактическое событие окончания трека для перехода в общей очереди. Доступность проигрывания зависит от сервиса и входа; часы не имитируются.

Personal radio now uses SoundCloud web discovery without API keys and starts a clearly labelled library mix immediately. Track clicks keep the library open, with persistent bottom playback controls. Actual web-media end events advance the shared queue.
