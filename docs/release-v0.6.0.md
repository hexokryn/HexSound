## Русский

HexSound — SoundCloud для Windows с отдельным плеером, текстами песен и настройкой оформления.

- 32 темы, светлый и тёмный режим.
- 9 анимированных фонов, режим без эффекта и свои изображения.
- Анимации текста, импорт LRC, парение и поворот обложки.
- Вход внутри приложения, профиль, библиотека, лайки и плейлисты через SoundCloud.
- Скрытие боковой панели, адаптивный интерфейс и работа в трее.
- Чёрный логотип «Пульс» и анимация запуска.
- Исправлено обрезание кнопок на узких карточках.

**Установка:** `HexSound-0.6.0-setup.exe`. **Без установки:** `HexSound-0.6.0-portable.exe`. Обе сборки для Windows x64. Профиль хранится в `%APPDATA%/HexSound`, в том числе у Portable. Перед обновлением завершите предыдущую версию через меню трея.

Сборки не подписаны, автоматическое обновление не реализовано. Нужен доступ к SoundCloud; ограничения сервиса сохраняются. Видео `HexSound-telegram.mp4` содержит демонстрационный трек и собственный текст.

## English

HexSound is a SoundCloud desktop app for Windows with a dedicated player, lyrics and appearance settings. The app UI is currently in Russian.

32 themes, light and dark modes, nine animated backgrounds plus a still mode, custom images, animated lyrics, LRC imports and artwork motion. SoundCloud sign-in, library, likes and playlists work through the embedded service page. The sidebar collapses, the layout adapts, and playback can stay in the tray. This release adds Setup alongside Portable and fixes clipped artwork action buttons.

Use `HexSound-0.6.0-setup.exe` to install or `HexSound-0.6.0-portable.exe` to run without installation. Both are Windows x64 builds. Both store the profile in `%APPDATA%/HexSound`. Quit the previous version from the tray before updating.

Builds are unsigned; there are no automatic updates. SoundCloud must be reachable and its restrictions apply. The attached MP4 uses demo data and an original soundtrack. `SHA256SUMS.txt` contains file checksums.
