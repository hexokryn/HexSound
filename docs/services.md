# SoundCloud: вход и API

Обычный веб-вход находится в настройках SoundCloud и внизу боковой панели. Его профиль использует Qt WebEngine и сохраняется между запусками. C++-версия не читает cookies или браузерные токены старой Electron-версии; войдите повторно.

Для прослушивания API не требуется. Для создания плейлистов используйте отдельное API-подключение собственного приложения SoundCloud: Client ID, Client Secret, redirect URI http://127.0.0.1:8766/callback/soundcloud. Services::connectAccount запускает системный браузер, PKCE S256 и локальный callback со state. Альтернатива — API access token, выданный вам SoundCloud. Веб-сессионный токен не подходит для этого поля.

Callback ограничивает Host, путь и размер запроса; просроченные ответы игнорируются. /me проверяет профиль, GET может однократно обновить OAuth-токен через refresh, запросы записи автоматически не повторяются. На Windows секреты хранятся с DPAPI, на Linux только в памяти. Не коммитить секреты и не выводить их в логи.

Реализация: native/Services.h и native/Services.cpp. Настройки: native/qml/Main.qml. Работа с частным аккаунтом и реальная запись API в этой сессии не проверены.
