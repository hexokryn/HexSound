# SoundCloud API для переноса

Для прослушивания API не требуется: войдите в SoundCloud через профиль внизу боковой панели.

Для создания плейлиста из CSV, TSV или JSON откройте **Настройки → API SoundCloud**. Подключите собственное приложение SoundCloud через Client ID, Client Secret и Redirect URI или используйте свой Access Token. Пароль SoundCloud в этих полях не нужен. Ключи хранятся в главном процессе с защитой системного хранилища; без него остаются только в памяти.

Перенос сначала ищет совпадения, затем показывает неоднозначные записи для проверки. Новый плейлист создаётся только после команды пользователя. При смене целевого аккаунта совпадения нужно проверить заново. Неопределённые результаты записи автоматически не повторяются; результаты доступны в настройках.

Подключения других музыкальных сервисов удалены. Их экспортированные файлы можно импортировать как списки названий и исполнителей.
