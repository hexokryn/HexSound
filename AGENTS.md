# HexSound — контекст для следующих агентов

## Текущий запрос

Приложение снова предназначено только для SoundCloud. Пользователь отменил единую медиатеку, остальные сервисы, отдельный аудиодвижок и лишние экраны. Сохранить прежнее оформление, темы и текст песни, сделать панели спокойнее. Rust отменён и не входит в проект.

Волну и перенос пользователь явно попросил сохранить. Перенос — только из файлов в SoundCloud, без подключений других сервисов. Для прослушивания используется обычный веб-вход, для создания плейлиста нужен отдельный SoundCloud API-доступ. Не обещать запись через обычную сессию.

## Структура

Описание файлов и проверок находится в docs/development.ru.md. src/main.cjs управляет изолированным WebContentsView с persist:soundcloud. Каталог, лайки, плейлисты и история — официальные страницы с CSS HexSound. Нижний и полноэкранный плеер управляют этим же сайтом. soundcloud-experience.cjs обслуживает волну и очередь подборки. file-imports.json хранит отдельный список для переноса, library.json — кэш SoundCloud для волны.

Удалены старые экраны единой медиатеки, окна других сервисов, локальное аудио/HLS, мини-плеер и их неиспользуемые зависимости. Метаданные старых экспортов остаются допустимым форматом импорта, это не подключение сервисов. Пользовательские данные прежних версий автоматически не удалять.

## Проверки и ограничения

npm ci; npm test; npm run check:experience. Последняя проверка использует локальную страницу с настоящим WAV в изолированной веб-сессии, тестирует play/pause из нижней панели и SPA-навигацию. Это не проверка частного аккаунта SoundCloud. Проверять упакованные EXE и Linux-приложение. На этой машине npm: node .tools/package/bin/npm-cli.js.

Sandbox/contextIsolation сохранять. Не извлекать cookies или браузерные токены. Секреты API — только в главном процессе и системном хранилище, иначе в памяти. Перенос требует проверки совпадений и того же целевого аккаунта; неопределённые записи не повторять автоматически. Часы плеера и результаты операций не имитировать.

src/updates.cjs использует Node fetch: Electron net.fetch отменяет ручной редирект GitHub. Адреса редиректов, размер и SHA-256 проверяются. Повторная проверка перед установкой обязательна. В тестах установку не запускать.

Эффекты скрытого окна освобождают canvas; включаются только по выбору пользователя. Не менять оформление заново и не добавлять новые возможности без запроса.

В Git и релизы не добавлять release/, artifacts/, .tools/, node_modules/, материалы для Telegram или видео. Ссылку автора https://t.me/zexokkydev в README сохранить. Удалённые пользователем тесты не восстанавливать. Опубликованные релизы не перезаписывать.
