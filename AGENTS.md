# HexSound — контекст для следующих агентов

## Приоритет пользователя

Сохранить прежний дизайн и исправить расход ОЗУ. Пользователь отменил перенос на Rust после оценки интерфейса. Рабочее приложение — Electron, HTML/CSS и JavaScript; переписывать его заново или упрощать оформление без отдельного запроса нельзя. Черновик Rust сохранён локально в игнорируемой папке artifacts/rust-preview и не входит в сборку.

## Что это за проект

Музыкальное desktop-приложение для Windows и Linux с единой библиотекой SoundCloud, Spotify, YouTube и экспериментальной Яндекс Музыки. Собственные экраны библиотеки, очереди, «Моей волны», переноса, настроек и плеера с синхронизированным текстом. Есть локальные файлы, теги, умные плейлисты, статистика и мини-плеер. Оформление: 32 темы, фоны и анимации, скрываемая боковая панель, минимальный логотип из трёх полос.

## Структура

- src/main.cjs — Electron, окна, IPC, сессии, навигация, опрос плеера и smoke-аудиты.
- src/preload.cjs — ограниченный мост к доверенному интерфейсу.
- src/index.html, styles.css, personalization.css, player.css, library.css, features.css — прежний интерфейс.
- src/renderer.js, player-renderer.js, library-renderer.js, features-renderer.js — экраны и отображение состояния.
- src/visual-system.js, atmosphere.js, lyric-motion.js, artwork-motion.js — темы, фон и анимации.
- src/features/ — очередь, radio, локальные файлы, медиапрокси, история и журнал переносов.
- src/library/ — импорт, нормализация, объединение источников, поиск совпадений и перенос.
- src/services/ — API, PKCE OAuth, защищённое хранение и адаптеры сервисов.
- src/service-windows.cjs — изолированные официальные веб-плееры.
- src/audio-engine.js — собственное аудио/HLS; src/mini* — мини-плеер.
- test/ — регрессионные Node-тесты; scripts/ — необходимые утилиты сборки.
- docs/ и README.md/README.en.md — документация RU/EN и реальные скриншоты.
- release/, artifacts/, .tools/, node_modules/ — локальные результаты; в Git не включать.

## Текущая оптимизация памяти

SoundCloud должен загружаться по запросу, а не вместе со стартовой медиатекой. Отключённый или невидимый фон не должен держать полноэкранный canvas-буфер; видимый эффект должен восстанавливаться без изменения внешнего вида. Опрос воспроизведения читает одну текущую запись, не копирует всю очередь и все оценки. HLS имеет ограниченный буфер; старые сегменты медиапрокси освобождаются при смене трека. Закрытый неиграющий сервис выгружается, играющий продолжает работать.

## Проверки

npm ci; npm test; npm run check:library; npm run check:experience. На этой машине npm доступен как node .tools/package/bin/npm-cli.js. Windows-сборка: npm run dist -- --publish never; Linux: npm run dist:linux -- --publish never. Проверять упакованный EXE, а не только исходники. Для метрик есть electron . --memory-test --memory-label=after; --memory-remote явно загружает сайт для сравнения. Не выдавать расчёт размера canvas за измерение всей памяти процесса.

Сохранять sandbox/contextIsolation; не отключать защиту ради RAM. Токены — только в главном процессе/OS-хранилище, при отсутствии защищённого хранилища только в памяти. Не экспортировать секреты, cookies и физические пути аудиофайлов. Не извлекать браузерные токены. API-вход и веб-сессия различаются.

Перенос требует проверки совпадений и того же целевого аккаунта. Не повторять автоматически неопределённые записи и создание плейлиста. Перед продолжением читать полный состав назначения. Не удалять аудиофайлы при удалении папки из индекса. Не подделывать успешные операции, результаты radio и часы текста.

В репозиторий и релизы не добавлять материалы для Telegram, видео, промотексты и инструменты их генерации. Ссылку автора https://t.me/zexokkydev в README сохранить. Не возвращать удалённые пользователем тесты/файлы без причины. Опубликованные релизы не перезаписывать; новую сборку публиковать после проверок.
