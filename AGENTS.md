# HexSound — текущая разработка

Последний запрос пользователя: переписать приложение на C++ и полностью переделать интерфейс, сделать настройки удобнее. Это явно отменяет прежний запрет на смену языка и дизайна. Rust не используется.

## Границы продукта

Только SoundCloud. Сохранены обычный вход, воспроизведение через официальный сайт, лайки, плейлисты, история, собственный нижний плеер, текст песни, темы, волна и импорт файлов. Подключения Spotify, YouTube Music и Яндекс Музыки не возвращать. Импорт — только CSV/TSV/JSON в новый плейлист SoundCloud. Для записи нужен отдельный API-доступ; обычная веб-сессия не заменяет API.

## Стек и запуск

C++20 / CMake / Qt Quick QML / Qt WebEngine. Точка входа native/main.cpp, оболочка native/qml/Main.qml, логика native/Controller.cpp, API native/Services.cpp, форматы native/MusicData.cpp. JavaScript в native/assets нужен только для DOM и mediaSession официального сайта. Node.js и Electron в новой сборке не используются.

Windows: python scripts/install-qt.py, затем ./scripts/build-native.ps1 -Test -Deploy. Релизный SDK: Qt 6.12.1 и отдельный Qt WebEngine 6.140.0. Скрипт учитывает раздельные репозитории новых SDK и проверяет суммы архивов из официального HTTPS-репозитория. Старый aqt 3.3.0 искал неверный каталог metadata. Первоначальные локальные проверки выполнены на .tools/Qt/6.8.3/msvc2022_64; их нельзя выдавать за проверку 6.12.1. Публикация Windows разрешена только после успешных проверок на релизном SDK.

Подробности: docs/development.ru.md. Целевая версия 0.13.0. Фактическое состояние публикации проверять в GitHub Releases. Старые опубликованные релизы не перезаписывать. Workflow публикует новый Windows-релиз только по коммиту main с префиксом Release или ручному publish; проверки, упаковка и тест отката должны пройти до публикации.

28 ноября 2026 опубликован Windows-релиз v0.13.0: Setup, native-portable.zip и SHA256SUMS. GitHub Actions run 46158076143, Windows job 141019023620 прошёл на Qt 6.12.1 / WebEngine 6.140.0: все unit, smoke сборки и папки без Qt в PATH, упаковка и тесты отката. Локальный запуск нового WebEngine из среды Codex возвращал renderer exit 18; это отличается от успешной проверки CI, причину не считать доказанной. Linux с Qt 6.12.1 собрался и прошёл три набора unit, но GUI-smoke завершился ошибкой загрузки xcb-плагина; Linux-пакеты не опубликованы.

## Проверки

native_tests и controller_tests; затем HexSound.exe --smoke artifacts/native-smoke. Smoke использует отдельный профиль и настоящий локальный WAV, проверяет play/pause/volume, скрытый каталог, SPA-навигацию и QML. Это не проверка частного аккаунта SoundCloud и API-записи. Обязательно повторить smoke на развернутой папке без Qt в PATH. Linux проверять отдельно, не объявлять готовым по одной Windows-сборке. Установщик обновления в тестах не запускать.

## Сессии и данные

У C++-версии отдельный профиль WebEngine. Не извлекать cookies, браузерные токены и не переносить их из Electron вручную. Существующие данные старой версии не удалять. API-секреты: Windows DPAPI, на Linux только память. Перенос проверяет совпадения, журнал и аккаунт назначения; неизвестные операции автоматически не повторять.

Удалённые страницы не получают QWebChannel, Backend или доступ к файловой системе. Не отключать sandbox WebEngine. Геолокацию, микрофон и прочие запрашиваемые сайтом разрешения по умолчанию отклонять. Проверять адреса редиректов, размер и SHA-256 обновлений; перед установкой проверять файл повторно.

Эффекты фона по умолчанию выключены; их Loader освобождается при скрытии/сворачивании. Временная страница волны уничтожается после чтения результатов. Не подменять часы плеера и результаты сетевых операций.

В Git и релизы не добавлять .tools/, release/, artifacts/, node_modules/, профили и материалы Telegram. Ссылку https://t.me/zexokkydev в README сохранить. PROJECT_HANDOFF.md создан по отдельному запросу и в этой работе не обновлялся; его описание Electron историческое.
